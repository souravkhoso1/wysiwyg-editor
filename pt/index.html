    O que você pode fazer com este editor

    • Formatar texto — negrito, itálico, sublinhado, tachado, subscrito e sobrescrito pela barra de ferramentas.
    • Estruturar o documento — aplique os títulos de nível 1 a 6 para ter seções claras e uma boa hierarquia.
    • Adicionar listas — listas com marcadores ou numeradas com um clique.
    • Controlar fontes e cores — escolha entre sete famílias de fontes e sete tamanhos predefinidos, e use qualquer cor de texto ou de fundo.
    • Inserir links e imagens — cole uma URL para criar um hiperlink, incorpore uma imagem da web ou envie uma do seu dispositivo.

    • Criar tabelas — insira grades de até 4 × 4 e adicione ou remova linhas e colunas quando quiser.
    • Localizar e substituir — pesquise no documento com destaque passo a passo e substitua uma ocorrência ou todas de uma vez.
    • Alternar para Markdown — escreva em Markdown com pré-visualização ao vivo em painéis divididos e volte ao texto formatado quando quiser.
    • Compartilhar com um link — clique no botão Compartilhar para gerar uma URL que restaura exatamente o seu documento para quem abri-la.
    • Exportar — baixe o documento como um arquivo HTML independente ou abra uma visualização em PDF pronta para impressão.

    O RichText.online é um editor de texto formatado WYSIWYG gratuito, que funciona no navegador. Escreva e formate documentos com negrito, itálico, sublinhado, tachado, títulos (H1–H6), listas com marcadores e numeradas, cor do texto, cor de fundo, família e tamanho da fonte, links, imagens e linhas horizontais. Alterne para o modo Markdown para ter uma pré-visualização ao vivo em painéis divididos, mostre o código-fonte HTML ou exporte o documento como um arquivo HTML independente — tudo sem criar uma conta.

    Lista completa de recursos

    Formatação de texto

    Aplique negrito, itálico, sublinhado e tachado a qualquer seleção. Eleve ou rebaixe caracteres com sobrescrito e subscrito para notação científica, notas de rodapé e fórmulas químicas. Remova toda a formatação de uma vez com o botão Limpar formatação.

    Títulos e estrutura de parágrafos

    Use a lista suspensa Título para aplicar os níveis H1 a H6. Títulos bem estruturados facilitam a navegação em documentos longos e melhoram a acessibilidade para quem usa leitores de tela.

    Listas

    Crie listas com marcadores para conjuntos de itens e listas numeradas para instruções passo a passo. Use Aumentar e Diminuir recuo para criar sublistas aninhadas em vários níveis de hierarquia.

    Fontes e cores

    Escolha entre sete famílias de fontes — Arial, Comic Sans MS, Courier, Georgia, Tahoma, Times New Roman e Verdana — e sete tamanhos predefinidos, de Minúsculo a Enorme. Selecione qualquer cor para o texto e para o realce de fundo com o seletor de cores nativo.

    Links e imagens

    Selecione o texto e clique no ícone de link para transformá-lo em hiperlink, ou remova um link com um clique. Insira imagens por URL, envie um arquivo direto do seu dispositivo ou incorpore um vídeo do YouTube ou do Vimeo colando a URL — tudo sem sair do editor.

    Tabelas

    Insira uma tabela de até 4 × 4 células pelo menu da barra de ferramentas. Depois de inserida, coloque o cursor em qualquer célula e use o menu Tabela para adicionar uma linha abaixo, excluir uma linha, adicionar uma coluna à direita ou excluir uma coluna. A primeira linha é formatada automaticamente como cabeçalho.

    Citações e blocos de código

    Formate um parágrafo como citação para destacar uma referência ou um trecho importante. Transforme qualquer parágrafo em bloco de código para exibir comandos, trechos de código ou outro conteúdo em fonte monoespaçada.

    Localizar e substituir

    Abra a barra Localizar e substituir (ou pressione Ctrl+H / ⌘+H) para pesquisar no documento com os resultados destacados. Percorra os resultados um a um com os botões de seta, substitua ocorrências individuais ou todas de uma só vez.

    Modo Markdown

    Ative o modo Markdown para escrever em sintaxe Markdown simples, com um painel de pré-visualização renderizada ao lado. A pré-visualização é atualizada enquanto você digita. Volte ao modo de texto formatado a qualquer momento para continuar formatando pela barra de ferramentas.

    Visualização do código HTML

    Clique no botão Código para ver e editar o HTML por trás do documento. É útil para colar conteúdo de outros sistemas, resolver problemas de formatação ou criar manualmente elementos HTML que a barra de ferramentas não oferece.

    Exportar e imprimir

    Baixe o documento como um arquivo HTML independente que pode ser aberto em qualquer navegador — útil para arquivar ou compartilhar offline. Abra uma visualização em PDF pronta para impressão e imprima direto ou salve como PDF pela caixa de diálogo de impressão do navegador.

    Compartilhar por URL

    Clique no botão Compartilhar para comprimir o conteúdo do documento e codificá-lo em uma URL compartilhável. Quem abrir o link vê o mesmo documento, pronto para ler ou editar — sem conta, sem servidor e sem anexos. Para documentos muito longos, uma opção com GitHub Gist gera um link mais curto.

    Salvamento automático

    Seu conteúdo é salvo automaticamente no armazenamento local do navegador enquanto você digita, com um pequeno atraso para evitar gravações excessivas. Ao fechar e reabrir a aba, você retoma exatamente de onde parou, sem nenhuma etapa manual de salvamento.

    Modo escuro e tela cheia

    Ative o modo escuro para editar com conforto em ambientes de pouca luz. Passe para a tela cheia para expandir o editor por toda a janela do navegador e ocultar todo o resto, para escrever sem distrações.

    Caracteres especiais e emojis

    Abra o seletor de caracteres para inserir com um clique símbolos de uso comum — copyright ©, marca registrada ®, marca ™, símbolos de moeda, setas, frações, pontuação tipográfica — além de uma seleção de emojis.

    Atalhos de teclado

    Os atalhos de teclado padrão funcionam em todo o editor: Ctrl+B para negrito, Ctrl+I para itálico, Ctrl+U para sublinhado, Ctrl+Z para desfazer, Ctrl+Y (ou ⌘+Shift+Z no Mac) para refazer e Ctrl+H para abrir Localizar e substituir. Pressione Enter na barra de URL para confirmar e Esc para fechá-la.

    Como usar o RichText.online

    1. Abra o editor. O editor fica pronto assim que a página carrega — sem login, sem extensão e sem instalação. Se você já usou antes, seu conteúdo anterior é restaurado automaticamente.
    2. Escreva seu conteúdo. Clique em qualquer lugar da área de edição e comece a digitar. O editor funciona como um processador de texto: Enter para um novo parágrafo e Tab para recuar dentro das listas.
    3. Aplique a formatação. Selecione o texto com o mouse ou o teclado e clique em um botão da barra de ferramentas para aplicar negrito, itálico, sublinhado, um nível de título, uma cor ou qualquer outro formato. A formatação é aplicada à seleção imediatamente.
    4. Insira links e mídia. Clique no ícone de link para associar uma URL ao texto selecionado. Clique no ícone de imagem para incorporar uma imagem a partir de um endereço da web, ou use o ícone de envio de arquivo para escolher uma imagem do seu computador. Cole uma URL do YouTube ou do Vimeo na barra de vídeo para adicionar um vídeo reproduzível.
    5. Organize com tabelas. Clique no ícone de tabela para inserir uma grade. Clique dentro de uma célula para posicionar o cursor e use o menu Tabela para adicionar ou remover linhas e colunas conforme seus dados crescem.
    6. Compartilhe o documento. Clique no botão azul Compartilhar da barra de ferramentas para abrir a caixa de compartilhamento. Copie a URL gerada e envie para quem quiser — a pessoa abrirá o mesmo documento no navegador, sem precisar de conta.
    7. Exporte ao terminar. Clique no ícone de download para salvar o documento como arquivo HTML, ou no ícone de PDF para abrir uma visualização de impressão. Use a caixa de diálogo de impressão do navegador para salvar como PDF ou enviar para uma impressora.

    Usos comuns

    Rascunhos de posts de blog

    Escreva e formate um rascunho com títulos, subtítulos, destaques em negrito e hiperlinks. Quando terminar, exporte como HTML para colar direto no seu CMS ou envie a URL de compartilhamento a um editor para revisão.

    E-mails formatados

    Escreva um e-mail com marcadores, texto colorido e uma imagem incorporada. Copie o conteúdo formatado do editor e cole no seu cliente de e-mail para manter a formatação rica.

    Anotações rápidas e atas de reunião

    Abra o editor em uma aba do navegador e registre as anotações da reunião com itens de ação numerados. O salvamento automático mantém seu conteúdo seguro e o link de compartilhamento permite distribuir a ata para toda a equipe na hora.

    Relatórios e documentação

    Monte relatórios estruturados com hierarquia de títulos, tabelas de dados, citações para fontes e linhas horizontais para separar seções. Exporte como HTML para incorporar em ferramentas internas ou wikis.

    Colaboração em conteúdo

    Escreva um documento, clique em Compartilhar e envie a URL para um colega. Ele abre no navegador, faz as edições e compartilha de volta — sem drives compartilhados, sem arquivos de versões e sem login de nenhum dos lados.

    Escrita em Markdown

    Prefere escrever em Markdown? Ative o modo Markdown para ter uma tela dividida ao vivo: Markdown puro à esquerda e HTML renderizado à direita. Copie o resultado renderizado ou volte ao modo de texto formatado para continuar editando pela barra de ferramentas.

    Incorpore o editor no seu próprio site

    Quer este editor no seu site? Adicione um contêiner e uma tag script. O editor é carregado em um frame isolado, e a sua página pode ler ou definir o conteúdo com algumas linhas de JavaScript.

    <div id="editor"></div>
<script src="https://richtext.online/embed.js"></script>
<script>
  var ed = RichTextEditor.create('#editor', { height: 400 });
  ed.onChange(function (html) { /* save html */ });
</script>

    Veja o guia completo de incorporação e a demonstração ao vivo (em inglês). Os editores incorporados não incluem login, salvamento na nuvem nem histórico de versões, e nunca acessam os documentos que seus visitantes salvaram no RichText.online. O HTML retornado pelo editor é criado pelo usuário, então sanitize-o antes de exibi-lo em outro lugar. O RichText.online registra estatísticas de uso anônimas dos editores incorporados, incluindo o domínio do site que os incorpora.

    Perguntas frequentes

    O RichText.online é gratuito?

    Sim — totalmente gratuito, sem limites de uso, sem plano pago e sem necessidade de conta. Abra a página e comece a escrever imediatamente.

    Onde meu conteúdo é armazenado?

    Seu conteúdo é salvo automaticamente no armazenamento local do navegador, no seu próprio dispositivo. Nada é enviado a nenhum servidor. Limpar os dados do navegador apaga o conteúdo salvo, então use Exportar ou Compartilhar para criar uma cópia permanente.

    Como funciona o compartilhamento?

    Ao clicar em Compartilhar, o HTML do documento é comprimido e codificado diretamente na URL. O navegador de quem recebe descomprime e exibe o documento — nenhum servidor está envolvido e nenhum dado é armazenado. Para documentos muito grandes, em que a URL ficaria longa demais, a opção GitHub Gist guarda o conteúdo no GitHub e gera um link curto.

    Posso colar conteúdo do Word ou do Google Docs?

    Sim. O editor limpa automaticamente a marcação proprietária do Microsoft Word ao colar, removendo tags XML ocultas, estilos inline e comentários condicionais que, de outra forma, quebrariam o layout. A formatação básica — negrito, itálico, títulos, listas e links — é mantida.

    Funciona offline?

    Depois que a página carrega, você pode escrever e formatar conteúdo sem conexão com a internet. A barra de ferramentas, o salvamento automático, a exportação e a impressão funcionam offline. O recurso Compartilhar (método de fragmento de URL) também gera o link offline, mas o método GitHub Gist exige conexão de rede para chamar a API do GitHub.

    Posso usar no celular?

    Sim. A barra de ferramentas é responsiva e se reorganiza em telas pequenas. A área de edição funciona com os teclados de celular. Para a melhor experiência no celular, use uma versão atual do Chrome, Safari ou Firefox.

    Como insiro uma imagem?

    Há duas formas. Clique no ícone de imagem por URL (moldura) para colar o endereço de uma imagem hospedada em outro lugar. Clique no ícone de envio de arquivo (foto com um sinal de mais) para escolher um arquivo de imagem do seu dispositivo — ela é incorporada diretamente ao documento como URI de dados em base64, então não é preciso hospedagem externa.

    O que é o modo Markdown?

    O modo Markdown substitui o editor por uma visão dividida: uma área de texto simples à esquerda, onde você escreve em sintaxe Markdown, e uma pré-visualização HTML ao vivo à direita, que é atualizada enquanto você digita. É útil se você prefere escrever em Markdown, mas quer ver o resultado na hora. Use o botão MD para alternar entre o modo Markdown e o modo de texto formatado.
