    RichText.online 是一款免费的、基于浏览器的所见即所得富文本编辑器。您可以使用粗体、斜体、下划线、删除线、标题 (H1–H6)、项目符号和编号列表、文字颜色、背景颜色、字体、字号、链接、图片和水平线来撰写并排版文档。切换到 Markdown 模式即可获得分栏实时预览，也可以查看 HTML 源代码，或将文档导出为独立的 HTML 文件——全程无需创建账号。

    完整功能列表

    文本格式

    可对任意选中内容应用粗体、斜体、下划线和删除线。使用上标和下标，可为科学记数、脚注和化学式抬高或降低字符。点击“清除格式”按钮即可一次移除所有行内格式。

    标题和段落结构

    通过“标题”下拉菜单应用 H1 至 H6 级标题。结构清晰的标题让长文档更易于浏览，也能改善屏幕阅读器用户的无障碍体验。

    列表

    用项目符号列表罗列一组条目，用编号列表撰写分步说明。使用“增加缩进”和“减少缩进”可创建多层级的嵌套子列表。

    字体和颜色

    可从七种字体中选择——Arial、Comic Sans MS、Courier、Georgia、Tahoma、Times New Roman 和 Verdana——以及从“极小”到“超大”的七种预设字号。文字颜色和背景高亮颜色可通过系统自带的取色器任意设置。

    链接和图片

    选中文字后点击链接图标即可添加超链接，也可一键移除链接。您可以通过网址插入图片，直接从设备上传文件，或粘贴网址嵌入 YouTube 或 Vimeo 视频——全部无需离开编辑器。

    表格

    从工具栏菜单中插入最多 4 × 4 单元格的表格。插入后，将光标置于任意单元格中，通过“表格”菜单可在下方添加行、删除行、在右侧添加列或删除列。第一行会自动设为表头。

    引用和代码块

    将段落设为引用，可突出显示出处或重要段落。将任意段落切换为代码块，可用等宽字体显示命令行、代码片段或其他内容。

    查找和替换

    打开“查找和替换”栏（或按 Ctrl+H / ⌘+H），即可在文档中搜索并高亮匹配项。用箭头按钮逐个跳转结果，可替换单个匹配项，也可一次替换全部。

    Markdown 模式

    切换到 Markdown 模式，即可用简单的 Markdown 语法写作，旁边的窗格会实时渲染预览，并随输入更新。随时可切回富文本模式，继续使用工具栏设置格式。

    HTML 源代码视图

    点击“源代码”按钮即可查看和编辑文档背后的原始 HTML。这有助于粘贴来自其他系统的内容、排查格式问题，或手工编写工具栏未提供的 HTML 元素。

    导出和打印

    将文档下载为独立的 HTML 文件，可在任何浏览器中打开，便于归档或离线分享。也可打开适合打印的 PDF 视图，直接打印，或通过浏览器的打印对话框另存为 PDF。

    通过链接分享

    点击“分享”按钮，即可压缩文档内容并编码为可分享的网址。打开链接的人将看到相同的文档，可直接阅读或编辑——无需账号、无需服务器、无需附件。对于特别长的文档，可选的 GitHub Gist 方式会生成更短的链接。

    自动保存

    输入时，您的内容会自动保存到浏览器的本地存储中，并带有短暂延迟，以避免频繁写入。关闭后重新打开标签页，即可回到上次的位置，无需任何手动保存步骤。

    深色模式和全屏

    切换到深色模式，在弱光环境下编辑更舒适。切换到全屏可让编辑器铺满整个浏览器窗口并隐藏其他内容，带来不受打扰的写作体验。

    特殊字符和表情符号

    打开字符选择器，一键插入常用符号——版权符号 ©、注册商标 ®、商标 ™、货币符号、箭头、分数、排版标点——以及精选的表情符号。

    键盘快捷键

    编辑器中通用的快捷键均可使用：Ctrl+B 粗体，Ctrl+I 斜体，Ctrl+U 下划线，Ctrl+Z 撤销，Ctrl+Y（Mac 上为 ⌘+Shift+Z）重做，Ctrl+H 打开“查找和替换”。在网址栏中按 Enter 确认，按 Esc 关闭。

    如何使用 RichText.online

    1. 打开编辑器。页面加载完成后编辑器即可使用——无需登录，无需扩展程序，无需安装。如果您以前使用过，之前的内容会自动恢复。
    2. 撰写内容。点击编辑区域的任意位置，开始输入。编辑器的使用方式与文字处理软件类似：按 Enter 开始新段落，在列表中按 Tab 进行缩进。
    3. 应用格式。用鼠标或键盘选中文字，然后点击工具栏按钮，即可应用粗体、斜体、下划线、标题级别、颜色或其他格式。格式会立即应用到所选内容。
    4. 插入链接和媒体。点击链接图标，可为所选文字添加网址。点击图片图标可通过网址嵌入图片，或使用上传文件图标从电脑中选择图片。将 YouTube 或 Vimeo 网址粘贴到视频嵌入栏，即可添加可播放的视频。
    5. 用表格整理内容。点击表格图标插入网格。点击任意单元格放置光标，然后通过“表格”菜单随数据增加或减少行和列。
    6. 分享文档。点击工具栏中蓝色的“分享”按钮，打开分享对话框。复制生成的网址并发送给任何人——对方无需账号，即可在浏览器中打开同一份文档。
    7. 完成后导出。点击下载图标可将文档保存为 HTML 文件，点击 PDF 图标可打开打印视图。通过浏览器的打印对话框可另存为 PDF 或发送到打印机。

    常见用途

    博客文章草稿

    使用标题、小标题、粗体强调和超链接撰写并排版草稿。完成后可导出为 HTML 直接粘贴到您的内容管理系统，或把分享链接发给编辑审阅。

    带格式的电子邮件

    撰写包含项目符号、彩色文字和嵌入图片的邮件。从编辑器中复制带格式的内容并粘贴到邮件客户端，即可保留丰富的格式。

    快速笔记和会议纪要

    在浏览器标签页中打开编辑器，用编号的待办事项记录会议笔记。自动保存确保内容安全，分享链接让您能立即把纪要发给整个团队。

    报告和文档

    使用层级标题、数据表格、用于引用资料来源的引用块，以及用于分隔章节的水平线，构建结构清晰的报告。可导出为 HTML，嵌入内部工具或维基。

    内容协作

    写好文档，点击“分享”，把网址发给同事。对方在浏览器中打开、修改后再分享回来——无需共享网盘，无需版本文件，双方都不必登录。

    用 Markdown 写作

    更喜欢用 Markdown 写作？切换到 Markdown 模式即可使用实时分屏：左侧是原始 Markdown，右侧是渲染后的 HTML。您可以复制渲染结果，也可以切换到富文本模式，继续使用工具栏编辑。

    常见问题

    RichText.online 是免费的吗？

    是的，完全免费，没有使用限制，没有付费方案，也不需要账号。打开页面即可立即开始写作。

    我的内容保存在哪里？

    您的内容会自动保存在您自己设备上浏览器的本地存储中，不会发送到任何服务器。清除浏览器数据会删除已保存的内容，因此请使用“导出”或“分享”来创建永久副本。

    分享是如何实现的？

    点击“分享”会压缩您文档的 HTML，并直接编码到网址中。接收者的浏览器会将其解压并显示文档——不涉及任何服务器，也不会在任何地方存储数据。对于网址会长得不切实际的超大文档，可选的 GitHub Gist 方式会把内容存放到 GitHub，并生成一个短链接。

    可以粘贴 Word 或 Google 文档中的内容吗？

    可以。粘贴时，编辑器会自动清理 Microsoft Word 的专有标记，移除隐藏的 XML 标签、行内样式和条件注释，以免破坏版式。粗体、斜体、标题、列表和链接等基本格式会被保留。

    可以离线使用吗？

    页面加载完成后，即使没有网络连接，您也可以继续写作和设置格式。工具栏、自动保存、导出和打印均可离线使用。分享功能（网址片段方式）同样可以离线生成链接，但 GitHub Gist 方式需要网络连接来调用 GitHub API。

    可以在手机上使用吗？

    可以。工具栏为响应式设计，在小屏幕上会自动换行。编辑区域支持手机键盘。要在手机上获得最佳体验，请使用最新版本的 Chrome、Safari 或 Firefox。

    如何插入图片？

    有两种方式。点击“通过网址插入图片”图标（相框），粘贴外部托管图片的网址。点击上传文件图标（带加号的照片），从设备中选择图片文件——它会以 Base64 数据 URI 的形式直接嵌入文档，无需外部托管。

    什么是 Markdown 模式？

    Markdown 模式会把编辑器换成分屏视图：左侧是纯文本区域，您可以用 Markdown 语法书写；右侧是实时 HTML 预览，随输入更新。如果您喜欢用 Markdown 写作，又想立即看到渲染效果，这会很方便。点击 MD 按钮可在 Markdown 模式和富文本模式之间切换。
