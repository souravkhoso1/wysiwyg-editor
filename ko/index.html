    RichText.online은 브라우저에서 사용하는 무료 WYSIWYG 서식 텍스트 편집기입니다. 굵게, 기울임, 밑줄, 취소선, 제목(H1–H6), 글머리 기호 및 번호 목록, 글자 색, 배경색, 글꼴, 글자 크기, 링크, 이미지, 가로줄로 문서를 작성하고 꾸밀 수 있습니다. Markdown 모드로 전환하면 분할 화면 실시간 미리보기를 볼 수 있고, HTML 소스를 확인하거나 문서를 독립형 HTML 파일로 내보낼 수도 있습니다. 계정을 만들 필요가 없습니다.

    전체 기능 목록

    텍스트 서식

    선택한 영역에 굵게, 기울임, 밑줄, 취소선을 적용할 수 있습니다. 위 첨자와 아래 첨자로 과학 표기, 각주, 화학식을 위한 문자 위치를 올리거나 내릴 수 있습니다. 서식 지우기 버튼으로 모든 인라인 서식을 한 번에 제거하세요.

    제목과 문단 구조

    제목 드롭다운에서 H1부터 H6까지 제목 수준을 적용하세요. 잘 짜인 제목은 긴 문서를 탐색하기 쉽게 만들고 화면 낭독기 사용자의 접근성도 높여 줍니다.

    목록

    항목 모음에는 글머리 기호 목록을, 단계별 안내에는 번호 목록을 만드세요. 들여쓰기와 내어쓰기를 사용하면 여러 단계의 중첩 하위 목록을 만들 수 있습니다.

    글꼴과 색상

    일곱 가지 글꼴(Arial, Comic Sans MS, Courier, Georgia, Tahoma, Times New Roman, Verdana)과 '아주 작게'부터 '최대'까지 일곱 가지 글자 크기 중에서 선택하세요. 글자 색과 배경 강조 색은 기본 색상 선택기로 자유롭게 지정할 수 있습니다.

    링크와 이미지

    텍스트를 선택하고 링크 아이콘을 클릭하면 하이퍼링크가 만들어지며, 한 번의 클릭으로 링크를 제거할 수도 있습니다. 웹 주소로 이미지를 삽입하거나, 기기에서 파일을 바로 업로드하거나, YouTube·Vimeo 주소를 붙여넣어 동영상을 삽입할 수 있습니다. 모두 편집기를 벗어나지 않고 할 수 있습니다.

    표

    도구 모음 메뉴에서 최대 4 × 4 셀의 표를 삽입하세요. 삽입한 뒤 셀 안에 커서를 놓고 표 메뉴에서 아래에 행 추가, 행 삭제, 오른쪽에 열 추가, 열 삭제를 할 수 있습니다. 첫 번째 행은 자동으로 머리글 행으로 서식이 지정됩니다.

    인용과 코드 블록

    문단을 인용으로 지정해 출처나 중요한 구절을 돋보이게 하세요. 문단을 코드 블록으로 바꾸면 명령줄, 코드 조각 등 고정폭 내용을 표시할 수 있습니다.

    찾기 및 바꾸기

    찾기 및 바꾸기 막대(또는 Ctrl+H / ⌘+H)를 열면 일치하는 부분이 강조 표시되며 문서를 검색할 수 있습니다. 화살표 버튼으로 결과를 하나씩 이동하고, 개별 항목을 바꾸거나 모든 항목을 한 번에 바꿀 수 있습니다.

    Markdown 모드

    Markdown 모드로 전환하면 일반 Markdown 문법으로 작성하면서 옆의 미리보기 창에서 결과를 바로 볼 수 있습니다. 미리보기는 입력에 맞춰 갱신됩니다. 언제든 서식 있는 텍스트 모드로 돌아가 도구 모음으로 서식을 계속 지정할 수 있습니다.

    HTML 소스 보기

    소스 버튼을 클릭하면 문서의 원본 HTML을 보고 편집할 수 있습니다. 다른 시스템의 내용을 붙여넣거나, 서식 문제를 해결하거나, 도구 모음에 없는 HTML 요소를 직접 만들 때 유용합니다.

    내보내기와 인쇄

    문서를 어떤 브라우저에서든 열 수 있는 독립형 HTML 파일로 내려받으세요. 보관이나 오프라인 공유에 유용합니다. 인쇄용 PDF 보기를 열어 바로 인쇄하거나 브라우저 인쇄 대화상자에서 PDF로 저장할 수 있습니다.

    URL로 공유

    공유 버튼을 클릭하면 문서 내용이 압축되어 공유 가능한 URL로 인코딩됩니다. 링크를 연 사람은 같은 문서를 읽거나 편집할 수 있으며 계정, 서버, 첨부 파일이 필요 없습니다. 매우 긴 문서의 경우 선택 사항인 GitHub Gist 방식으로 더 짧은 링크를 만들 수 있습니다.

    자동 저장

    입력하는 동안 내용이 브라우저의 로컬 저장소에 자동으로 저장되며, 과도한 쓰기를 막기 위해 짧은 지연이 있습니다. 탭을 닫았다가 다시 열어도 직접 저장하지 않고 중단한 곳에서 그대로 이어서 작업할 수 있습니다.

    다크 모드와 전체 화면

    다크 모드로 전환하면 어두운 환경에서도 편안하게 편집할 수 있습니다. 전체 화면으로 전환하면 편집기가 브라우저 창 전체로 확장되고 나머지는 숨겨져 방해 없이 글쓰기에 집중할 수 있습니다.

    특수 문자와 이모지

    문자 선택기를 열어 자주 쓰는 기호(저작권 ©, 등록 상표 ®, 상표 ™, 통화 기호, 화살표, 분수, 타이포그래피 문장 부호)와 엄선된 이모지를 한 번의 클릭으로 삽입하세요.

    키보드 단축키

    편집기 전반에서 표준 단축키를 사용할 수 있습니다. Ctrl+B는 굵게, Ctrl+I는 기울임, Ctrl+U는 밑줄, Ctrl+Z는 실행 취소, Ctrl+Y(Mac에서는 ⌘+Shift+Z)는 다시 실행, Ctrl+H는 찾기 및 바꾸기입니다. URL 입력줄에서는 Enter로 확인하고 Esc로 닫습니다.

    RichText.online 사용 방법

    1. 편집기 열기. 페이지가 로드되면 바로 사용할 수 있습니다. 로그인, 확장 프로그램, 설치가 필요 없습니다. 이전에 방문한 적이 있다면 이전 내용이 자동으로 복원됩니다.
    2. 내용 작성. 편집 영역의 아무 곳이나 클릭하고 입력을 시작하세요. 편집기는 워드 프로세서처럼 동작합니다. Enter로 새 문단을 만들고, 목록 안에서는 Tab으로 들여쓰기를 합니다.
    3. 서식 적용. 마우스나 키보드로 텍스트를 선택한 다음 도구 모음 버튼을 클릭해 굵게, 기울임, 밑줄, 제목 수준, 색상 등 원하는 서식을 적용하세요. 서식은 선택 영역에 즉시 적용됩니다.
    4. 링크와 미디어 삽입. 링크 아이콘을 클릭해 선택한 텍스트에 URL을 연결하세요. 이미지 아이콘으로 웹 주소의 이미지를 삽입하거나, 파일 업로드 아이콘으로 컴퓨터에서 이미지를 고를 수 있습니다. 동영상 삽입 막대에 YouTube 또는 Vimeo URL을 붙여넣으면 재생 가능한 동영상이 추가됩니다.
    5. 표로 정리하기. 표 아이콘을 클릭해 표를 삽입하세요. 셀을 클릭해 커서를 놓고, 데이터가 늘어나면 표 메뉴로 행과 열을 추가하거나 삭제하세요.
    6. 문서 공유. 도구 모음의 파란색 공유 버튼을 클릭해 공유 대화상자를 여세요. 생성된 URL을 복사해 누구에게나 보내면, 받은 사람은 계정 없이 브라우저에서 같은 문서를 열 수 있습니다.
    7. 완료 후 내보내기. 다운로드 아이콘을 클릭해 문서를 HTML 파일로 저장하거나, PDF 아이콘을 클릭해 인쇄 보기를 여세요. 브라우저 인쇄 대화상자에서 PDF로 저장하거나 프린터로 보낼 수 있습니다.

    주요 활용 사례

    블로그 글 초안

    제목, 소제목, 굵은 강조, 하이퍼링크로 초안을 작성하고 꾸미세요. 완성하면 HTML로 내보내 CMS에 바로 붙여넣거나, 공유 URL을 편집자에게 보내 검토를 요청할 수 있습니다.

    서식이 있는 이메일

    글머리 기호, 색상 있는 글자, 삽입한 이미지가 들어간 이메일을 작성하세요. 편집기에서 서식 있는 내용을 복사해 메일 프로그램에 붙여넣으면 풍부한 서식이 유지됩니다.

    빠른 메모와 회의록

    브라우저 탭에서 편집기를 열고 번호가 매겨진 할 일 항목과 함께 회의 메모를 작성하세요. 자동 저장으로 내용이 안전하게 보관되고, 공유 링크로 회의록을 팀 전체에 즉시 전달할 수 있습니다.

    보고서와 문서

    제목 계층, 데이터 표, 출처 인용, 구역을 나누는 가로줄을 사용해 구조가 잡힌 보고서를 만드세요. HTML로 내보내 사내 도구나 위키에 삽입할 수 있습니다.

    콘텐츠 협업

    문서를 작성하고 공유를 클릭한 뒤 URL을 동료에게 보내세요. 동료는 브라우저에서 열어 수정하고 다시 공유해 줍니다. 공유 드라이브도, 버전 파일도, 양쪽 로그인도 필요 없습니다.

    Markdown으로 글쓰기

    Markdown으로 쓰는 것을 선호하시나요? Markdown 모드로 전환하면 실시간 분할 화면이 열립니다. 왼쪽에는 원본 Markdown, 오른쪽에는 렌더링된 HTML이 표시됩니다. 렌더링된 결과를 복사하거나, 서식 있는 텍스트 모드로 전환해 도구 모음으로 계속 편집할 수 있습니다.

    내 웹사이트에 편집기 삽입하기

    이 편집기를 내 사이트에서 쓰고 싶으신가요? 컨테이너와 script 태그 하나만 추가하면 됩니다. 편집기는 격리된 프레임에서 로드되며, 페이지에서는 몇 줄의 JavaScript로 내용을 읽거나 설정할 수 있습니다.

    <div id="editor"></div>
<script src="https://richtext.online/embed.js"></script>
<script>
  var ed = RichTextEditor.create('#editor', { height: 400 });
  ed.onChange(function (html) { /* save html */ });
</script>

    전체 삽입 가이드와 라이브 데모 보기(영어). 삽입된 편집기에는 로그인, 클라우드 저장, 버전 기록이 포함되지 않으며, 방문자가 RichText.online에 저장한 문서에는 절대 접근하지 않습니다. 편집기가 반환하는 HTML은 사용자가 작성한 것이므로 다른 곳에 표시하기 전에 반드시 정제하세요. RichText.online은 삽입된 편집기의 익명 사용 통계를 수집하며, 여기에는 편집기를 삽입한 사이트의 도메인이 포함됩니다.

    자주 묻는 질문

    RichText.online은 무료인가요?

    네, 완전히 무료입니다. 사용 제한도, 유료 요금제도, 계정도 필요 없습니다. 페이지를 열고 바로 글을 쓰기 시작하세요.

    내 내용은 어디에 저장되나요?

    내용은 사용자 기기의 브라우저 로컬 저장소에 자동으로 저장되며, 어떤 서버로도 전송되지 않습니다. 브라우저 데이터를 지우면 저장된 내용도 삭제되므로, 영구적인 사본이 필요하면 내보내기나 공유를 사용하세요.

    공유는 어떻게 작동하나요?

    공유를 클릭하면 문서의 HTML이 압축되어 URL에 바로 인코딩됩니다. 받는 사람의 브라우저가 이를 압축 해제해 문서를 표시하므로 서버가 관여하지 않고 어디에도 데이터가 저장되지 않습니다. URL이 지나치게 길어지는 아주 큰 문서의 경우, 선택 사항인 GitHub Gist 방식이 내용을 GitHub에 저장하고 대신 짧은 링크를 만들어 줍니다.

    Word나 Google 문서에서 내용을 붙여넣을 수 있나요?

    네. 붙여넣을 때 편집기가 Microsoft Word의 고유 마크업을 자동으로 정리해, 레이아웃을 깨뜨릴 수 있는 숨겨진 XML 태그, 인라인 스타일, 조건부 주석을 제거합니다. 굵게, 기울임, 제목, 목록, 링크 같은 기본 서식은 유지됩니다.

    오프라인에서도 작동하나요?

    페이지가 로드된 후에는 인터넷 연결 없이도 글을 쓰고 서식을 지정할 수 있습니다. 도구 모음, 자동 저장, 내보내기, 인쇄는 오프라인에서 작동합니다. 공유 기능(URL 해시 방식)도 링크 생성은 오프라인에서 가능하지만, GitHub Gist 방식은 GitHub API를 호출하므로 네트워크 연결이 필요합니다.

    모바일에서도 사용할 수 있나요?

    네. 도구 모음은 반응형이라 작은 화면에서는 줄바꿈됩니다. 편집 영역은 모바일 키보드에서도 작동합니다. 모바일에서 최상의 환경을 위해 최신 버전의 Chrome, Safari 또는 Firefox를 사용하세요.

    이미지는 어떻게 삽입하나요?

    두 가지 방법이 있습니다. URL로 이미지 삽입 아이콘(액자)을 클릭해 외부에 호스팅된 이미지의 웹 주소를 붙여넣거나, 파일 업로드 아이콘(더하기가 있는 사진)을 클릭해 기기에서 이미지 파일을 선택하세요. 파일은 Base64 데이터 URI로 문서에 직접 삽입되므로 외부 호스팅이 필요 없습니다.

    Markdown 모드란 무엇인가요?

    Markdown 모드는 편집기를 분할 화면으로 바꿉니다. 왼쪽은 Markdown 문법으로 작성하는 일반 텍스트 영역이고, 오른쪽은 입력에 맞춰 갱신되는 실시간 HTML 미리보기입니다. Markdown으로 쓰면서 렌더링 결과를 바로 확인하고 싶을 때 유용합니다. MD 버튼으로 Markdown 모드와 서식 있는 텍스트 모드를 전환할 수 있습니다.
