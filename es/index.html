    RichText.online es un editor de texto enriquecido WYSIWYG gratuito que funciona en el navegador. Escribe y da formato a documentos con negrita, cursiva, subrayado, tachado, títulos (H1–H6), listas con viñetas y numeradas, color de texto, color de fondo, tipo de letra, tamaño de fuente, enlaces, imágenes y líneas horizontales. Cambia al modo Markdown para ver una vista previa en directo en paneles divididos, muestra el código fuente HTML o exporta tu documento como un archivo HTML independiente, todo sin crear una cuenta.

    Lista completa de funciones

    Formato de texto

    Aplica negrita, cursiva, subrayado y tachado a cualquier selección. Eleva o baja caracteres con superíndice y subíndice para notación científica, notas al pie y fórmulas químicas. Elimina todo el formato en línea de una vez con el botón Borrar formato.

    Títulos y estructura de párrafos

    Usa el menú desplegable Título para aplicar los niveles H1 a H6. Unos títulos bien estructurados facilitan la navegación por documentos largos y mejoran la accesibilidad para quienes usan lectores de pantalla.

    Listas

    Crea listas con viñetas para conjuntos de elementos y listas numeradas para instrucciones paso a paso. Usa Aumentar y Reducir sangría para crear sublistas anidadas con varios niveles de jerarquía.

    Fuentes y colores

    Elige entre siete tipos de letra (Arial, Comic Sans MS, Courier, Georgia, Tahoma, Times New Roman y Verdana) y siete tamaños predefinidos, de Diminuto a Enorme. Selecciona cualquier color para el texto y para el resaltado de fondo con el selector de color nativo.

    Enlaces e imágenes

    Selecciona texto y haz clic en el icono de enlace para convertirlo en un hipervínculo, o quita un enlace con un clic. Inserta imágenes desde una URL web, sube un archivo directamente desde tu dispositivo o incrusta un vídeo de YouTube o Vimeo pegando su URL, todo sin salir del editor.

    Tablas

    Inserta una tabla de hasta 4 × 4 celdas desde el menú de la barra de herramientas. Una vez insertada, coloca el cursor en cualquier celda y usa el menú Tabla para añadir una fila debajo, eliminar una fila, añadir una columna a la derecha o eliminar una columna. La primera fila recibe automáticamente formato de encabezado.

    Citas y bloques de código

    Da formato de cita a un párrafo para destacar una referencia o un pasaje importante. Convierte cualquier párrafo en un bloque de código para mostrar instrucciones de línea de comandos, fragmentos de código u otro contenido en fuente monoespaciada.

    Buscar y reemplazar

    Abre la barra Buscar y reemplazar (o pulsa Ctrl+H / ⌘+H) para buscar en tu documento con las coincidencias resaltadas. Recorre los resultados uno a uno con los botones de flecha, reemplaza coincidencias individuales o todas las apariciones a la vez.

    Modo Markdown

    Activa el modo Markdown para escribir con sintaxis Markdown simple y ver a su lado un panel de vista previa renderizada. La vista previa se actualiza mientras escribes. Vuelve al modo de texto enriquecido en cualquier momento para seguir dando formato con la barra de herramientas.

    Vista del código HTML

    Haz clic en el botón Código para ver y editar el HTML que hay detrás de tu documento. Es útil para pegar contenido de otros sistemas, resolver problemas de formato o crear a mano elementos HTML que la barra de herramientas no ofrece.

    Exportar e imprimir

    Descarga tu documento como un archivo HTML independiente que puedes abrir en cualquier navegador, útil para archivarlo o compartirlo sin conexión. Abre una vista PDF lista para imprimir y envíala directamente a la impresora o guárdala como PDF con el cuadro de diálogo de impresión del navegador.

    Compartir mediante URL

    Haz clic en el botón Compartir para comprimir el contenido de tu documento y codificarlo en una URL que puedes compartir. Quien abra el enlace verá el mismo documento, listo para leer o editar, sin cuenta, sin servidor y sin archivos adjuntos. Para documentos muy largos, una opción con GitHub Gist genera un enlace más corto.

    Guardado automático

    Tu contenido se guarda automáticamente en el almacenamiento local de tu navegador mientras escribes, con un breve retardo para evitar escrituras excesivas. Al cerrar y volver a abrir la pestaña, recuperas exactamente donde lo dejaste, sin ningún paso manual de guardado.

    Modo oscuro y pantalla completa

    Activa el modo oscuro para editar cómodamente con poca luz. Cambia a pantalla completa para ampliar el editor a toda la ventana del navegador y ocultar todo lo demás, para escribir sin distracciones.

    Caracteres especiales y emojis

    Abre el selector de caracteres para insertar con un clic símbolos de uso frecuente (copyright ©, marca registrada ®, marca ™, signos de moneda, flechas, fracciones, puntuación tipográfica) y una selección de emojis.

    Atajos de teclado

    Los atajos de teclado habituales funcionan en todo el editor: Ctrl+B para negrita, Ctrl+I para cursiva, Ctrl+U para subrayado, Ctrl+Z para deshacer, Ctrl+Y (o ⌘+Mayús+Z en Mac) para rehacer y Ctrl+H para abrir Buscar y reemplazar. Pulsa Intro en la barra de URL para confirmar y Esc para cerrarla.

    Cómo usar RichText.online

    1. Abre el editor. El editor está listo en cuanto carga la página: sin iniciar sesión, sin extensiones y sin instalación. Si ya lo has usado antes, tu contenido anterior se restaura automáticamente.
    2. Escribe tu contenido. Haz clic en cualquier punto del área de edición y empieza a escribir. El editor funciona como un procesador de texto: Intro para un párrafo nuevo y Tab para aplicar sangría dentro de las listas.
    3. Aplica formato. Selecciona texto con el ratón o el teclado y haz clic en un botón de la barra de herramientas para aplicar negrita, cursiva, subrayado, un nivel de título, un color o cualquier otro formato. El formato se aplica a la selección al instante.
    4. Inserta enlaces y contenido multimedia. Haz clic en el icono de enlace para asociar una URL al texto seleccionado. Haz clic en el icono de imagen para insertar una imagen desde una dirección web, o usa el icono de subir archivo para elegir una imagen de tu ordenador. Pega una URL de YouTube o Vimeo en la barra de vídeo para añadir un vídeo reproducible.
    5. Organiza con tablas. Haz clic en el icono de tabla para insertar una cuadrícula. Haz clic dentro de una celda para colocar el cursor y usa el menú Tabla para añadir o eliminar filas y columnas a medida que crecen tus datos.
    6. Comparte tu documento. Haz clic en el botón azul Compartir de la barra de herramientas para abrir el cuadro de compartir. Copia la URL generada y envíasela a quien quieras: abrirá el mismo documento en su navegador sin necesidad de cuenta.
    7. Exporta al terminar. Haz clic en el icono de descarga para guardar el documento como archivo HTML, o en el icono de PDF para abrir una vista de impresión. Usa el cuadro de diálogo de impresión del navegador para guardar como PDF o enviar a una impresora.

    Casos de uso habituales

    Borradores de entradas de blog

    Escribe y da formato a un borrador con títulos, subtítulos, negritas e hipervínculos. Cuando termines, exporta como HTML para pegarlo directamente en tu CMS o envía la URL para compartir a un editor para su revisión.

    Correos con formato

    Redacta un correo con viñetas, texto de color e imágenes incrustadas. Copia el contenido con formato desde el editor y pégalo en tu cliente de correo para conservar el formato enriquecido.

    Notas rápidas y actas de reuniones

    Abre el editor en una pestaña del navegador y toma notas de reuniones con puntos de acción numerados. El guardado automático protege tu contenido y el enlace para compartir te permite distribuir el acta a todo el equipo al instante.

    Informes y documentación

    Elabora informes estructurados con jerarquía de títulos, tablas de datos, citas para las fuentes y líneas horizontales para separar secciones. Exporta como HTML para incorporarlos a herramientas internas o wikis.

    Colaboración en contenidos

    Escribe un documento, haz clic en Compartir y envía la URL a un compañero. Lo abre en su navegador, hace cambios y te lo devuelve: sin unidades compartidas, sin archivos de versiones y sin necesidad de iniciar sesión en ningún lado.

    Escritura en Markdown

    ¿Prefieres escribir en Markdown? Activa el modo Markdown para tener una pantalla dividida en directo: Markdown sin procesar a la izquierda y HTML renderizado a la derecha. Copia el resultado o cambia al modo de texto enriquecido para seguir editando con la barra de herramientas.

    Inserta el editor en tu propio sitio web

    ¿Quieres este editor en tu sitio? Añade un contenedor y una etiqueta script. El editor se carga en un marco aislado y tu página puede leer o establecer su contenido con unas pocas líneas de JavaScript.

    <div id="editor"></div>
<script src="https://richtext.online/embed.js"></script>
<script>
  var ed = RichTextEditor.create('#editor', { height: 400 });
  ed.onChange(function (html) { /* save html */ });
</script>

    Consulta la guía completa de integración y la demostración en directo (en inglés). Los editores incrustados no incluyen inicio de sesión, guardado en la nube ni historial de versiones, y nunca tocan los documentos que tus visitantes hayan guardado en RichText.online. El HTML que devuelve el editor lo escribe el usuario, así que límpialo antes de mostrarlo en otro lugar. RichText.online registra estadísticas de uso anónimas de los editores incrustados, incluido el dominio del sitio que los incorpora.

    Preguntas frecuentes

    ¿RichText.online es gratuito?

    Sí, es totalmente gratuito, sin límites de uso, sin plan de pago y sin necesidad de cuenta. Abre la página y empieza a escribir de inmediato.

    ¿Dónde se almacena mi contenido?

    Tu contenido se guarda automáticamente en el almacenamiento local del navegador, en tu propio dispositivo. No se envía nada a ningún servidor. Si borras los datos del navegador, se eliminará el contenido guardado; usa Exportar o Compartir para crear una copia permanente.

    ¿Cómo funciona el uso compartido?

    Al hacer clic en Compartir se comprime el HTML de tu documento y se codifica directamente en la URL. El navegador del destinatario lo descomprime y muestra el documento: no interviene ningún servidor y no se almacena ningún dato. Para documentos muy grandes cuya URL sería demasiado larga, la opción de GitHub Gist guarda el contenido en GitHub y genera un enlace corto.

    ¿Puedo pegar contenido desde Word o Google Docs?

    Sí. El editor limpia automáticamente el marcado propietario de Microsoft Word al pegar, eliminando las etiquetas XML ocultas, los estilos en línea y los comentarios condicionales que de otro modo alterarían el diseño. Se conserva el formato básico: negrita, cursiva, títulos, listas y enlaces.

    ¿Funciona sin conexión?

    Una vez cargada la página, puedes escribir y dar formato al contenido sin conexión a internet. La barra de herramientas, el guardado automático, la exportación y la impresión funcionan sin conexión. La función Compartir (método de fragmento de URL) también permite generar el enlace sin conexión, pero el método GitHub Gist necesita conexión de red para llamar a la API de GitHub.

    ¿Puedo usarlo en el móvil?

    Sí. La barra de herramientas es adaptable y se reorganiza en pantallas pequeñas. El área de edición funciona con los teclados de los móviles. Para una mejor experiencia en el móvil, usa una versión actual de Chrome, Safari o Firefox.

    ¿Cómo inserto una imagen?

    Hay dos formas. Haz clic en el icono de imagen desde URL (marco de fotos) para pegar la dirección web de una imagen alojada en otro sitio. Haz clic en el icono de subir archivo (foto con un signo más) para elegir un archivo de imagen de tu dispositivo: se incrusta directamente en el documento como URI de datos en base64, por lo que no hace falta alojamiento externo.

    ¿Qué es el modo Markdown?

    El modo Markdown sustituye el editor por una vista dividida: a la izquierda, un área de texto plano donde escribes con sintaxis Markdown y, a la derecha, una vista previa HTML en directo que se actualiza mientras escribes. Es útil si prefieres escribir en Markdown pero quieres ver el resultado al instante. Usa el botón MD para alternar entre el modo Markdown y el modo de texto enriquecido.
