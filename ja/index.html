    RichText.online へようこそ

    ここに入力を始めてください — この案内文は、何か入力すると消えます。作業内容はブラウザに自動保存されるので、いつでも続きから再開できます。

    このエディタでできること

    • テキストの書式設定 — ツールバーから太字、斜体、下線、取り消し線、下付き文字、上付き文字を設定できます。
    • 文書の構造化 — 見出し1〜見出し6を使って、わかりやすい章立てと階層を作れます。
    • リストの追加 — 箇条書き、番号付きリストをワンクリックで作成できます。
    • フォントと色の設定 — 7種類のフォント、7段階のサイズから選び、文字色や背景色も自由に指定できます。
    • リンクと画像の挿入 — URLを貼り付けてリンクを作成したり、Web上の画像を埋め込んだり、端末から画像をアップロードしたりできます。
    • 動画の埋め込み — YouTubeまたはVimeoのリンクを貼り付けて、再生できる動画を挿入できます。
    • 表の作成 — 最大4×4の表を挿入し、行や列をいつでも追加・削除できます。
    • 検索と置換 — ハイライト表示で文書内を検索し、1件ずつまたは一括で置換できます。
    • Markdownへの切り替え — ライブプレビュー付きの2画面でMarkdownを書き、いつでもリッチテキストに戻せます。
    • リンクで共有 — 共有ボタンをクリックすると、開いた人に同じ文書を再現するURLが生成されます。
    • エクスポート — 文書を単独のHTMLファイルとしてダウンロードしたり、印刷用のPDF表示を開いたりできます。

    アカウントもインストールもファイル管理も不要です。すべてブラウザ上で直接動作します。

    単語数: 0 | 文字数: 0

    RichText.online は、ブラウザで使える無料のWYSIWYGリッチテキストエディタです。太字、斜体、下線、取り消し線、見出し (H1〜H6)、箇条書きと番号付きリスト、文字色、背景色、フォント、文字サイズ、リンク、画像、水平線を使って文書を作成・整形できます。Markdownモードでライブプレビュー付きの2画面表示に切り替えたり、HTMLソースを表示したり、文書を単独のHTMLファイルとしてエクスポートしたりできます。アカウント作成は不要です。

    機能一覧

    テキストの書式設定

    選択範囲に太字、斜体、下線、取り消し線を適用できます。上付き文字・下付き文字で、科学表記、脚注、化学式も表現できます。「書式をクリア」ボタンで、インライン書式をまとめて解除できます。

    見出しと段落構造

    見出しのドロップダウンでH1〜H6の見出しレベルを設定できます。構造化された見出しは、長い文書を読みやすくし、スクリーンリーダー利用者のアクセシビリティも向上させます。

    リスト

    項目の一覧には箇条書き、手順には番号付きリストを使えます。インデントを増やす・減らすボタンで、複数階層の入れ子リストも作成できます。

    フォントと色

    Arial、Comic Sans MS、Courier、Georgia、Tahoma、Times New Roman、Verdanaの7種類のフォントと、極小から最大までの7段階のサイズから選べます。文字色と背景のハイライト色は、標準のカラーピッカーで自由に指定できます。

    リンクと画像

    テキストを選択してリンクアイコンをクリックするとハイパーリンクを設定でき、ワンクリックで解除もできます。Web上のURLから画像を挿入したり、端末のファイルを直接アップロードしたり、URLを貼り付けてYouTubeやVimeoの動画を埋め込んだりできます。すべてエディタを離れずに操作できます。

    表

    ツールバーのメニューから最大4×4セルの表を挿入できます。挿入後は、任意のセルにカーソルを置き、表メニューから下への行の追加、行の削除、右への列の追加、列の削除ができます。1行目は自動的に見出し行として書式設定されます。

    引用とコードブロック

    段落を引用にして、出典の引用や重要な箇所を目立たせられます。段落をコード/整形済みブロックに切り替えると、コマンドライン、コードスニペット、その他の等幅コンテンツを表示できます。

    検索と置換

    検索と置換バー (Ctrl+H / ⌘+H) を開くと、一致箇所がハイライト表示されます。矢印ボタンで1件ずつ移動したり、個別に置換したり、すべてを一括で置換したりできます。

    Markdownモード

    Markdownモードに切り替えると、プレーンなMarkdown記法で書きながら、横に表示されるプレビューで結果を確認できます。プレビューは入力に合わせて更新されます。ツールバーで書式を設定したいときは、いつでもリッチテキストモードに戻せます。

    HTMLソース表示

    ソースボタンをクリックすると、文書の元になっているHTMLを表示・編集できます。他のシステムからの貼り付け、書式のトラブルシューティング、ツールバーにはないHTML要素の手作業での追加に便利です。

    エクスポートと印刷

    文書をどのブラウザでも開ける単独のHTMLファイルとしてダウンロードでき、保管やオフラインでの共有に便利です。印刷用のPDF表示を開いて、そのまま印刷したり、ブラウザの印刷ダイアログでPDFとして保存したりできます。

    URLで共有

    共有ボタンをクリックすると、文書の内容が圧縮され、共有用URLにエンコードされます。リンクを開いた人は同じ文書を閲覧・編集できます。アカウント、サーバー、ファイル添付は不要です。非常に長い文書には、より短いリンクを生成するGitHub Gistのオプションも利用できます。

    自動保存

    入力内容は、書き込みを減らすための短い遅延を置いて、ブラウザのローカルストレージに自動保存されます。タブを閉じて開き直しても、手動で保存しなくても、そのまま続きから再開できます。

    ダークモードと全画面表示

    ダークモードに切り替えると、暗い環境でも快適に編集できます。全画面表示ではエディタがブラウザ全体に広がり、他の要素が隠れるので、集中して執筆できます。

    特殊文字と絵文字

    文字パレットを開くと、著作権記号©、登録商標®、商標™、通貨記号、矢印、分数、約物などのよく使う記号や、厳選した絵文字をワンクリックで挿入できます。

    キーボードショートカット

    エディタ全体で標準的なショートカットが使えます。Ctrl+Bで太字、Ctrl+Iで斜体、Ctrl+Uで下線、Ctrl+Zで元に戻す、Ctrl+Y (MacではCmd+Shift+Z) でやり直し、Ctrl+Hで検索と置換を開きます。URLバーではEnterで確定、Escapeで閉じます。

    RichText.online の使い方

    1. エディタを開く。 ページを読み込むとすぐに使えます。ログイン、拡張機能、インストールは不要です。以前に使ったことがある場合は、前回の内容が自動的に復元されます。
    2. 内容を書く。 編集エリアをクリックして入力を始めます。ワープロと同じように、Enterで新しい段落、リスト内ではTabでインデントができます。
    3. 書式を設定する。 マウスまたはキーボードでテキストを選択し、ツールバーのボタンをクリックして、太字、斜体、下線、見出しレベル、色などを設定します。書式は選択範囲にすぐ反映されます。
    4. リンクとメディアを挿入する。 リンクアイコンをクリックして、選択したテキストにURLを設定します。画像アイコンでWebアドレスから画像を埋め込み、ファイルアップロードアイコンでパソコンから画像を選べます。YouTubeまたはVimeoのURLを動画埋め込みバーに貼り付けると、再生できる動画を追加できます。
    5. 表で整理する。 表アイコンをクリックして表を挿入します。セルをクリックしてカーソルを置き、表メニューでデータの増減に合わせて行や列を追加・削除します。
    6. 文書を共有する。 ツールバーの青い共有ボタンをクリックして共有ダイアログを開きます。生成されたURLをコピーして送れば、相手はアカウントなしで同じ文書をブラウザで開けます。
    7. 完成したらエクスポートする。 ダウンロードアイコンでHTMLファイルとして保存するか、PDFアイコンで印刷表示を開きます。ブラウザの印刷ダイアログからPDFとして保存したり、プリンターに送ったりできます。

    主な使い方

    ブログ記事の下書き

    見出し、小見出し、太字の強調、ハイパーリンクを使って下書きを作成します。完成したらHTMLとしてエクスポートしてCMSに貼り付けたり、共有URLを編集者に送ってレビューを依頼したりできます。

    書式付きメール

    箇条書き、色付きテキスト、埋め込み画像を使ったメールを作成します。エディタから書式付きの内容をコピーしてメールソフトに貼り付ければ、リッチな書式が保たれます。

    クイックメモと議事録

    ブラウザのタブでエディタを開き、番号付きのアクション項目とともに会議のメモを取れます。自動保存で内容が守られ、共有リンクで議事録をチーム全員にすぐ配布できます。

    レポートとドキュメント

    見出しの階層、データ表、出典付きの引用、セクションを区切る水平線を使って、構造化されたレポートを作成します。HTMLとしてエクスポートすれば、社内ツールやWikiに埋め込めます。

    コンテンツの共同作業

    文書を書いて共有をクリックし、URLを同僚に送ります。相手はブラウザで開いて編集し、また共有し返せます。共有ドライブもバージョン管理ファイルも、どちらのログインも不要です。

    Markdownでの執筆

    Markdownで書きたい方は、Markdownモードに切り替えてライブ分割画面を使えます。左に生のMarkdown、右にレンダリング済みのHTMLが表示されます。レンダリング結果をコピーするか、リッチテキストモードに切り替えてツールバーで編集を続けられます。

    エディタを自分のウェブサイトに埋め込む

    このエディタを自分のサイトで使いたいですか？ コンテナと1つのスクリプトタグを追加するだけです。エディタは分離されたフレーム内で読み込まれ、ページ側から数行のJavaScriptで内容を読み取ったり設定したりできます。

    <div id="editor"></div>
<script src="https://richtext.online/embed.js"></script>
<script>
  var ed = RichTextEditor.create('#editor', { height: 400 });
  ed.onChange(function (html) { /* save html */ });
</script>

    埋め込みガイド全文とライブデモを見る（英語）。埋め込み版エディタには、ログイン、クラウド保存、バージョン履歴は含まれず、訪問者がRichText.onlineに保存した文書には一切触れません。エディタが返すHTMLはユーザーが作成したものなので、他の場所で表示する前にサニタイズしてください。RichText.onlineは、埋め込み版エディタの匿名の利用状況を、埋め込み先サイトのドメインを含めて記録します。

    よくある質問

    RichText.online は無料で使えますか？

    はい、完全無料です。利用制限も有料プランもなく、アカウントも不要です。ページを開けばすぐに書き始められます。

    内容はどこに保存されますか？

    内容は、お使いの端末のブラウザのローカルストレージに自動保存されます。サーバーには何も送信されません。ブラウザのデータを消去すると保存内容も消えるため、永続的なコピーが必要な場合はエクスポートまたは共有を使ってください。

    共有はどのように動作しますか？

    共有をクリックすると、文書のHTMLが圧縮され、URLに直接エンコードされます。受け取った人のブラウザがそれを展開して文書を表示します。サーバーは関与せず、データはどこにも保存されません。URLが現実的でないほど長くなる大きな文書では、オプションのGitHub Gistを使うと、内容をGitHubに保存して短いリンクを生成できます。

    WordやGoogleドキュメントから貼り付けできますか？

    はい。貼り付け時に、Microsoft Word独自のマークアップを自動的に除去します。レイアウトを崩す原因となる非表示のXMLタグ、インラインスタイル、条件付きコメントが取り除かれ、太字、斜体、見出し、リスト、リンクなどの基本的な書式は保持されます。

    オフラインでも使えますか？

    ページを読み込んだ後は、インターネット接続なしで文章の入力と書式設定ができます。ツールバー、自動保存、エクスポート、印刷はオフラインでも動作します。共有機能 (URLハッシュ方式) もリンクの生成はオフラインで可能ですが、GitHub Gist方式はGitHub APIを呼び出すためネットワーク接続が必要です。

    モバイルでも使えますか？

    はい。ツールバーはレスポンシブで、小さい画面では折り返して表示されます。編集エリアはモバイルのキーボードでも使えます。モバイルでは、最新バージョンのChrome、Safari、Firefoxをおすすめします。

    画像はどのように挿入しますか？

    2つの方法があります。画像のURLアイコン (額縁) をクリックして、外部にホストされている画像のWebアドレスを貼り付けます。ファイルアップロードアイコン (プラス付きの写真) をクリックして、端末から画像ファイルを選びます。画像はBase64のデータURIとして文書に直接埋め込まれるため、外部ホスティングは不要です。

    Markdownモードとは何ですか？

    Markdownモードでは、エディタが分割表示に切り替わります。左側のプレーンテキスト領域にMarkdown記法で書くと、右側のライブHTMLプレビューが入力に合わせて更新されます。Markdownで書きたいけれど結果をすぐ確認したい方に便利です。MDボタンで、Markdownモードとリッチテキストモードを切り替えられます。
