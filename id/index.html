    RichText.online adalah editor teks kaya WYSIWYG gratis berbasis browser. Tulis dan format dokumen dengan cetak tebal, miring, garis bawah, coret, judul (H1–H6), daftar berpoin dan bernomor, warna teks, warna latar, jenis huruf, ukuran huruf, tautan, gambar, dan garis horizontal. Beralih ke mode Markdown untuk pratinjau langsung dengan dua panel, tampilkan sumber HTML, atau ekspor dokumen Anda sebagai file HTML mandiri — semuanya tanpa membuat akun.

    Daftar fitur lengkap

    Pemformatan teks

    Terapkan cetak tebal, miring, garis bawah, dan coret pada bagian mana pun yang dipilih. Naikkan atau turunkan karakter dengan superskrip dan subskrip untuk notasi ilmiah, catatan kaki, dan rumus kimia. Hapus semua format sebaris sekaligus dengan tombol Hapus format.

    Judul dan struktur paragraf

    Gunakan menu tarik-turun Judul untuk menerapkan tingkat judul H1 sampai H6. Judul yang terstruktur dengan baik memudahkan navigasi dokumen panjang dan meningkatkan aksesibilitas bagi pengguna pembaca layar.

    Daftar

    Buat daftar berpoin untuk kumpulan item dan daftar bernomor untuk petunjuk langkah demi langkah. Gunakan Tambah indentasi dan Kurangi indentasi untuk membuat sublist bersarang dengan beberapa tingkat hierarki.

    Jenis huruf dan warna

    Pilih dari tujuh jenis huruf — Arial, Comic Sans MS, Courier, Georgia, Tahoma, Times New Roman, dan Verdana — dan tujuh ukuran huruf bawaan dari Sangat kecil sampai Raksasa. Pilih warna apa pun untuk teks dan sorotan latar dengan pemilih warna bawaan.

    Tautan dan gambar

    Blok teks lalu klik ikon tautan untuk menjadikannya hyperlink, atau hapus tautan dengan satu klik. Sisipkan gambar dari URL web, unggah file langsung dari perangkat Anda, atau sematkan video YouTube atau Vimeo dengan menempelkan URL-nya — semuanya tanpa meninggalkan editor.

    Tabel

    Sisipkan tabel hingga 4 × 4 sel dari menu bilah alat. Setelah disisipkan, letakkan kursor di sel mana pun dan gunakan menu Tabel untuk menambah baris di bawah, menghapus baris, menambah kolom di kanan, atau menghapus kolom. Baris pertama otomatis diformat sebagai baris judul.

    Kutipan dan blok kode

    Format paragraf sebagai kutipan untuk menonjolkan sitasi atau bagian penting. Ubah paragraf mana pun menjadi blok kode untuk menampilkan perintah baris perintah, cuplikan kode, atau konten monospasi lainnya.

    Cari dan ganti

    Buka bilah Cari dan ganti (atau tekan Ctrl+H / ⌘+H) untuk menelusuri dokumen dengan hasil yang disorot. Telusuri hasil satu per satu dengan tombol panah, ganti satu kecocokan, atau ganti semuanya sekaligus.

    Mode Markdown

    Aktifkan mode Markdown untuk menulis dengan sintaks Markdown biasa, dengan panel pratinjau hasil render di sebelahnya. Pratinjau diperbarui saat Anda mengetik. Kembali ke mode teks kaya kapan saja untuk melanjutkan pemformatan dengan bilah alat.

    Tampilan sumber HTML

    Klik tombol Sumber untuk melihat dan mengedit HTML mentah dari dokumen Anda. Ini berguna untuk menempel konten dari sistem lain, memecahkan masalah format, atau membuat sendiri elemen HTML yang tidak tersedia di bilah alat.

    Ekspor dan cetak

    Unduh dokumen Anda sebagai file HTML mandiri yang dapat dibuka di browser mana pun — berguna untuk pengarsipan atau berbagi secara offline. Buka tampilan PDF siap cetak untuk langsung mencetak atau menyimpannya sebagai PDF melalui dialog cetak browser.

    Bagikan lewat URL

    Klik tombol Bagikan untuk memampatkan isi dokumen dan menyandikannya menjadi URL yang dapat dibagikan. Siapa pun yang membuka tautan akan melihat dokumen yang sama, siap dibaca atau diedit — tanpa akun, tanpa server, tanpa lampiran file. Untuk dokumen yang sangat panjang, opsi GitHub Gist membuat tautan yang lebih pendek.

    Simpan otomatis

    Isi dokumen Anda disimpan otomatis ke penyimpanan lokal browser saat Anda mengetik, dengan jeda singkat untuk menghindari penulisan berlebihan. Menutup lalu membuka kembali tab akan mengembalikan Anda tepat ke posisi terakhir, tanpa langkah simpan manual.

    Mode gelap dan layar penuh

    Aktifkan mode gelap agar nyaman mengedit di tempat minim cahaya. Beralih ke layar penuh untuk memperluas editor ke seluruh jendela browser dan menyembunyikan yang lain, demi pengalaman menulis tanpa gangguan.

    Karakter khusus dan emoji

    Buka pemilih karakter untuk menyisipkan simbol yang sering dipakai dengan sekali klik — hak cipta ©, merek terdaftar ®, merek dagang ™, simbol mata uang, panah, pecahan, tanda baca tipografi — serta sejumlah emoji pilihan.

    Pintasan keyboard

    Pintasan keyboard standar berfungsi di seluruh editor: Ctrl+B untuk cetak tebal, Ctrl+I untuk miring, Ctrl+U untuk garis bawah, Ctrl+Z untuk urungkan, Ctrl+Y (atau ⌘+Shift+Z di Mac) untuk ulangi, Ctrl+H untuk membuka Cari dan ganti. Tekan Enter di bilah URL untuk mengonfirmasi dan Esc untuk menutupnya.

    Cara menggunakan RichText.online

    1. Buka editor. Editor siap dipakai begitu halaman selesai dimuat — tanpa masuk, tanpa ekstensi, tanpa pemasangan. Jika Anda pernah berkunjung sebelumnya, isi dokumen sebelumnya dipulihkan secara otomatis.
    2. Tulis konten Anda. Klik di mana saja pada area penyuntingan dan mulai mengetik. Editor bekerja seperti pengolah kata: tekan Enter untuk paragraf baru, Tab untuk indentasi di dalam daftar.
    3. Terapkan format. Pilih teks dengan mouse atau keyboard, lalu klik tombol di bilah alat untuk menerapkan cetak tebal, miring, garis bawah, tingkat judul, warna, atau format lainnya. Format langsung diterapkan pada bagian yang dipilih.
    4. Sisipkan tautan dan media. Klik ikon tautan untuk menambahkan URL ke teks yang dipilih. Klik ikon gambar untuk menyematkan gambar dari alamat web, atau gunakan ikon unggah file untuk memilih gambar dari komputer Anda. Tempel URL YouTube atau Vimeo ke bilah sematan video untuk menambahkan video yang dapat diputar.
    5. Susun dengan tabel. Klik ikon tabel untuk menyisipkan kisi. Klik di dalam sel untuk meletakkan kursor, lalu gunakan menu Tabel untuk menambah atau menghapus baris dan kolom seiring bertambahnya data Anda.
    6. Bagikan dokumen Anda. Klik tombol Bagikan berwarna biru di bilah alat untuk membuka dialog berbagi. Salin URL yang dihasilkan dan kirim ke siapa saja — mereka akan membuka dokumen yang sama di browser tanpa perlu akun.
    7. Ekspor setelah selesai. Klik ikon unduh untuk menyimpan dokumen sebagai file HTML, atau ikon PDF untuk membuka tampilan cetak. Gunakan dialog Cetak browser untuk menyimpan sebagai PDF atau mengirim ke printer.

    Kasus penggunaan umum

    Draf tulisan blog

    Tulis dan format draf dengan judul, subjudul, penekanan tebal, dan hyperlink. Setelah selesai, ekspor sebagai HTML untuk ditempel langsung ke CMS Anda, atau kirim URL berbagi ke editor untuk ditinjau.

    Email berformat

    Tulis email dengan poin-poin, teks berwarna, dan gambar tersemat. Salin konten berformat dari editor dan tempel ke aplikasi email Anda agar format kayanya tetap terjaga.

    Catatan cepat dan notulen rapat

    Buka editor di tab browser dan catat hasil rapat dengan butir tindakan bernomor. Simpan otomatis menjaga konten Anda tetap aman, dan tautan berbagi memungkinkan Anda mengirim notulen ke seluruh tim seketika.

    Laporan dan dokumentasi

    Susun laporan terstruktur dengan hierarki judul, tabel data, kutipan untuk sumber, dan garis horizontal untuk memisahkan bagian. Ekspor sebagai HTML untuk disematkan ke alat internal atau wiki.

    Kolaborasi konten

    Tulis dokumen, klik Bagikan, lalu kirim URL-nya ke rekan kerja. Mereka membukanya di browser, membuat perubahan, dan membagikannya kembali — tanpa drive bersama, tanpa file versi, tanpa perlu masuk di kedua sisi.

    Menulis dengan Markdown

    Lebih suka menulis dengan Markdown? Aktifkan mode Markdown untuk tampilan terbagi secara langsung: Markdown mentah di kiri, HTML hasil render di kanan. Salin hasil render atau beralih ke mode teks kaya untuk melanjutkan penyuntingan dengan bilah alat.

    Sematkan editor di situs web Anda sendiri

    Ingin menggunakan editor ini di situs Anda sendiri? Tambahkan sebuah kontainer dan satu tag script. Editor dimuat dalam frame terisolasi, dan halaman Anda dapat membaca atau mengatur isinya hanya dengan beberapa baris JavaScript.

    <div id="editor"></div>
<script src="https://richtext.online/embed.js"></script>
<script>
  var ed = RichTextEditor.create('#editor', { height: 400 });
  ed.onChange(function (html) { /* save html */ });
</script>

    Lihat panduan penyematan lengkap dan demo langsung (dalam bahasa Inggris). Editor tersemat tidak menyertakan fitur masuk, simpan ke cloud, atau riwayat versi, dan tidak pernah menyentuh dokumen yang disimpan pengunjung Anda di RichText.online. HTML yang dikembalikan editor dibuat oleh pengguna, jadi bersihkan terlebih dahulu sebelum menampilkannya di tempat lain. RichText.online mencatat statistik penggunaan anonim untuk editor tersemat, termasuk domain situs yang menyematkannya.

    Pertanyaan yang sering diajukan

    Apakah RichText.online gratis?

    Ya — sepenuhnya gratis tanpa batas penggunaan, tanpa paket berbayar, dan tanpa akun. Buka halaman ini dan langsung mulai menulis.

    Di mana konten saya disimpan?

    Konten Anda disimpan otomatis di penyimpanan lokal browser pada perangkat Anda sendiri. Tidak ada yang dikirim ke server mana pun. Menghapus data browser akan menghapus konten yang tersimpan, jadi gunakan Ekspor atau Bagikan untuk membuat salinan permanen.

    Bagaimana cara kerja berbagi?

    Mengklik Bagikan memampatkan HTML dokumen Anda dan menyandikannya langsung ke dalam URL. Browser penerima mengurai kembali dan menampilkan dokumen — tidak ada server yang terlibat dan tidak ada data yang disimpan di mana pun. Untuk dokumen yang sangat besar sehingga URL-nya terlalu panjang, opsi GitHub Gist menyimpan konten di GitHub dan membuat tautan pendek sebagai gantinya.

    Bisakah saya menempel konten dari Word atau Google Docs?

    Bisa. Editor otomatis membersihkan markah milik Microsoft Word saat Anda menempel, menghapus tag XML tersembunyi, gaya sebaris, dan komentar bersyarat yang dapat merusak tata letak. Format dasar — cetak tebal, miring, judul, daftar, dan tautan — tetap dipertahankan.

    Apakah bisa dipakai secara offline?

    Setelah halaman dimuat, Anda dapat menulis dan memformat konten tanpa koneksi internet. Bilah alat, simpan otomatis, ekspor, dan cetak semuanya berfungsi offline. Fitur Bagikan (metode fragmen URL) juga dapat membuat tautan secara offline, tetapi metode GitHub Gist memerlukan koneksi jaringan untuk memanggil API GitHub.

    Bisakah saya memakainya di ponsel?

    Bisa. Bilah alat bersifat responsif dan membungkus ke baris berikutnya di layar kecil. Area penyuntingan berfungsi dengan keyboard ponsel. Untuk pengalaman terbaik di ponsel, gunakan Chrome, Safari, atau Firefox versi terbaru.

    Bagaimana cara menyisipkan gambar?

    Ada dua cara. Klik ikon sisipkan gambar dari URL (bingkai foto) untuk menempel alamat web gambar yang dihosting di tempat lain. Klik ikon unggah file (foto dengan tanda tambah) untuk memilih file gambar dari perangkat Anda — gambar disematkan langsung ke dokumen sebagai URI data base64, sehingga tidak perlu hosting eksternal.

    Apa itu mode Markdown?

    Mode Markdown mengganti editor dengan tampilan terbagi: area teks biasa di kiri tempat Anda menulis dalam sintaks Markdown, dan pratinjau HTML langsung di kanan yang diperbarui saat Anda mengetik. Ini berguna jika Anda lebih suka menulis dalam Markdown tetapi ingin langsung melihat hasil render. Gunakan tombol MD untuk beralih antara mode Markdown dan mode teks kaya.

    Bahasa yang tersedia

    RichText.online tersedia dalam bahasa-bahasa di bawah ini. Bahasa Inggris adalah bahasa bawaan.
