RichText.online is a free, browser-based WYSIWYG rich text editor. Write and format documents with bold, italic, underline, strikethrough, headings (H1–H6), bullet and numbered lists, text colour, background colour, font family, font size, links, images and horizontal rules. Switch to Markdown mode for a live split-pane preview, toggle source HTML view, or export your document as a standalone HTML file — all without creating an account.

Full feature list

Text formatting

Apply bold, italic, underline and strikethrough to any selection. Raise or lower characters with superscript and subscript for scientific notation, footnotes and chemical formulae. Remove all inline formatting at once with the Clear Formatting button.

Headings and paragraph structure

Use the Heading dropdown to apply H1 through H6 heading levels. Well-structured headings make long documents easier to navigate and improve accessibility for screen-reader users.

Lists

Create unordered (bullet) lists for collections of items and ordered (numbered) lists for step-by-step instructions. Use Indent and Outdent to create nested sub-lists with multiple levels of hierarchy.

Fonts and colours

Choose from seven font families — Arial, Comic Sans MS, Courier, Georgia, Tahoma, Times New Roman and Verdana — and seven size presets from Tiny to Huge. Pick any colour for text foreground and background highlight using the native colour picker.

Links and images

Highlight text and click the link icon to wrap it in a hyperlink, or remove a link with one click. Insert images from a web URL, upload a file directly from your device, or embed a YouTube or Vimeo video by pasting its URL — all without leaving the editor.

Tables

Insert a table of up to 4 × 4 cells from the toolbar menu. Once inserted, place your cursor in any cell and use the Table menu to add a row below, delete a row, add a column to the right, or delete a column. The first row is automatically formatted as a header row.

Blockquotes and code blocks

Format a paragraph as a blockquote to pull out a citation or highlight an important passage. Switch any paragraph to a code/pre block for displaying command-line instructions, code snippets or other monospace content.

Find and replace

Open the Find & Replace bar (or press Ctrl+H / ⌘+H) to search your document with highlighted matches. Step through results one at a time with the arrow buttons, replace individual matches, or replace all occurrences at once.

Markdown mode

Toggle Markdown mode to write in plain Markdown syntax with a live-rendered preview pane beside it. The preview updates as you type. Switch back to rich-text mode at any time to continue formatting with the toolbar.

Source HTML view

Click the Source button to view and edit the raw HTML behind your document. This is useful for pasting content from other systems, troubleshooting formatting, or hand-crafting HTML elements the toolbar does not expose.

Export and print

Download your document as a self-contained HTML file you can open in any browser — useful for archiving or sharing offline. Open a print-ready PDF view to print directly or save as a PDF using your browser's print dialog.

Share via URL

Click the Share button to compress your document content and encode it into a shareable URL. Anyone who opens the link sees the same document, ready to read or edit — no account, no server, no file attachment required. For very long documents, an optional GitHub Gist fallback generates a shorter link.

Auto-save

Your content is saved automatically to your browser's local storage as you type, with a short debounce delay to avoid excessive writes. Closing and reopening the tab restores exactly where you left off, without any manual save step.

Dark mode and fullscreen

Toggle Dark mode for comfortable editing in low-light environments. Switch to Fullscreen to expand the editor to the full browser window, hiding everything else for a distraction-free writing experience.

Special characters and emoji

Open the character picker to insert commonly used symbols — copyright ©, registered ®, trademark ™, currency signs, arrows, fractions, typographic punctuation — as well as a curated set of emoji, all at a single click.

Keyboard shortcuts

Standard keyboard shortcuts work throughout the editor: Ctrl+B for bold, Ctrl+I for italic, Ctrl+U for underline, Ctrl+Z to undo, Ctrl+Y (or ⌘+Shift+Z on Mac) to redo, Ctrl+H to open Find & Replace. Press Enter in the URL bar to confirm, and Escape to dismiss it.

How to use RichText.online

  1. Open the editor. The editor is ready to use as soon as the page loads — no sign-in, no extension, no installation needed. If you have visited before, your previous content is restored automatically.
  2. Write your content. Click anywhere in the editing area and start typing. The editor behaves like a word processor: press Enter for a new paragraph, Tab for indentation inside lists.
  3. Apply formatting. Select any text with your mouse or keyboard, then click a toolbar button to apply bold, italic, underline, a heading level, a colour, or any other format. Formatting is applied to the selection immediately.
  4. Insert links and media. Click the link icon to attach a URL to selected text. Click the image icon to embed an image from a web address, or use the file-upload icon to pick an image from your computer. Paste a YouTube or Vimeo URL into the video embed bar to add a playable video.
  5. Organise with tables. Click the table icon to insert a grid. Click inside any cell to position your cursor, then use the Table menu to add or remove rows and columns as your data grows.
  6. Share your document. Click the blue Share button in the toolbar to open the share dialog. Copy the generated URL and send it to anyone — they will open the same document in their browser without needing an account.
  7. Export when finished. Click the download icon to save your document as an HTML file, or click the PDF icon to open a print view. Use your browser's Print dialog to save as PDF or send to a printer.

Common use cases

Blog post drafts

Write and format a draft with headings, subheadings, bold emphasis and hyperlinks. When finished, export as HTML to paste directly into your CMS or send the share URL to an editor for review.

Formatted emails

Compose an email with bullet points, coloured text and an embedded image. Copy the formatted content from the editor and paste it into your email client to preserve the rich formatting.

Quick notes and meeting minutes

Open the editor in a browser tab and capture meeting notes with numbered action items. Auto-save keeps your content safe and the share link lets you distribute minutes to the whole team instantly.

Reports and documentation

Build structured reports using heading hierarchy, data tables, blockquotes for sourced material and horizontal rules to separate sections. Export as HTML for embedding in internal tools or wikis.

Content collaboration

Write a document, click Share, and send the URL to a colleague. They open it in their browser, make edits, and share it back — no shared drives, no version files, no login required on either end.

Markdown authoring

Prefer to write in Markdown? Toggle Markdown mode for a live split-screen: raw Markdown on the left, rendered HTML on the right. Copy the rendered output or switch to rich-text mode to continue editing with the toolbar.

Frequently asked questions

Is RichText.online free to use?

Yes — completely free with no usage limits, no paid plan and no account required. Open the page and start writing immediately.

Where is my content stored?

Your content is saved automatically to your browser's local storage on your own device. Nothing is sent to any server. Clearing your browser data will remove the saved content, so use Export or Share to create a permanent copy.

How does sharing work?

Clicking Share compresses your document's HTML and encodes it directly into the URL. The recipient's browser decompresses it and displays the document — no server is involved, and no data is stored anywhere. For very large documents where the URL would be impractically long, the optional GitHub Gist fallback stores the content on GitHub and generates a short link instead.

Can I paste content from Word or Google Docs?

Yes. The editor automatically cleans Microsoft Word's proprietary markup when you paste, removing hidden XML tags, inline styles and conditional comments that would otherwise break the layout. Basic formatting — bold, italic, headings, lists and links — is preserved.

Does it work offline?

Once the page has loaded, you can write and format content without an internet connection. The toolbar, auto-save, export and print all function offline. The Share feature (URL hash method) also works offline for generating the link, but the GitHub Gist method requires a network connection to call the GitHub API.

Can I use it on mobile?

Yes. The toolbar is responsive and wraps on smaller screens. The editing area works with mobile keyboards. For the best experience on mobile, use a current version of Chrome, Safari or Firefox.

How do I insert an image?

There are two ways. Click the image-from-URL icon (picture frame) to paste a web address for an externally hosted image. Click the file-upload icon (photo with a plus) to select an image file from your device — it is embedded directly into the document as a base-64 data URI, so no external hosting is needed.

What is Markdown mode?

Markdown mode replaces the editor with a split view: a plain-text area on the left where you write in Markdown syntax, and a live HTML preview on the right that updates as you type. It is useful if you prefer writing in Markdown but want to see the rendered output immediately. Toggle the MD button to switch between Markdown and rich-text modes.
